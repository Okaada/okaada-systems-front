What I do

Software and the infrastructure it runs on, as fixed-scope projects or ongoing support, always versioned and documented in your own repository.

Application development

  • C# and .NET applications and APIs

    ASP.NET Core services with automated tests, ready to run in containers on AWS. When your team already lives in Python, FastAPI services and Lambda automations.

  • Financial markets systems

    FX, derivatives and real-time pricing: low latency with a Disruptor-pattern ring buffer, the FIX protocol, FpML, Bloomberg integrations and streaming quotes over WebSocket.

Cloud and infrastructure

  • AWS architecture and migration

    Environments on ECS Fargate, RDS, S3, Lambda and Step Functions, plus migrations between clouds or regions without stopping the business. I have led a full platform move from GCP to AWS.

  • Infrastructure as code

    Modular Terraform, protected remote state and reproducible environments. Nothing clicked together in the console, everything reviewable in a pull request.

  • CI/CD and supply chain security

    GitHub Actions pipelines with OIDC instead of static keys, actions pinned by SHA, least-privilege permissions and defenses against compromised npm packages.

  • Edge protection with Cloudflare

    WAF, rules against abuse and lookalike domains, CDN, R2 and Workers to take load and risk off your origin.

  • Cost governance

    Mandatory tagging, hunting down orphaned resources and spend visible per product, so the cloud bill stops being a surprise.

  • Infrastructure security and privacy compliance

    Posture reviews with an offensive mindset: IAM, data exposure, logging and audit trails aligned with Brazil's LGPD.

The advantage of doing both: the person writing the application also designs where it runs. Performance, cost and security get decided together instead of being passed between teams.
